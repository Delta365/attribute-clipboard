Tip: organize with folders

Add a / in a group's name to nest it inside a folder. Naming a group buttons/primary puts it under a folder called buttons.

Folders nest as deep as you want, so ui/cards/elevated creates a three-level tree.

You can rename folder headers later to restructure on the fly.
